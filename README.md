# ტენდერ რადარი

სახელმწიფო შესყიდვების ტენდერები ნაკლები კონკურენციით (tenders.procurement.gov.ge).

- `index.html` - გვერდი
- `data.json` - ყოველდღიური მონაცემები (ახლდება დილის დავალებით)
- `pipeline.js` - შეგროვების სკრიპტი (ეშვება ბრაუზერში, პორტალის გვერდზე)
- `tg_post.js` - Telegram არხის პოსტი
